Preguntas frecuentes

¿Es seguro vincular mi WhatsApp?

La vinculación usa WhatsApp Web mediante una biblioteca no oficial. Puedes revocarla desde tu teléfono en cualquier momento.

¿Qué pasa si expira el código?

WhatsApp renueva el código automáticamente. Si la conexión falla, pulsa "Generar nuevo código" para reintentar.

¿Puedo usar mi número personal?

Recomendamos WhatsApp Business. Un número personal también funciona, aunque con menos funciones.
